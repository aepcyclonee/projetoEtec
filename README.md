// Passo a passo para clonar o repositório do Github para o VScode: <br>
1. Abra o navegador e faça log-in no GitHub <br>
2. Abra o Visual Studio Code <br>
3. Conecte a conta do Github com o VS Code no perfil <br>
4. Abra o terminal <br>
5. Volte ao C:\\ com o comando 'cd\' <br>
6. Crie um repositório com o comando 'Mkdir + nome' <br>
7. Inicie a ação do github com 'git init' <br>
8. Clone o repositório <br>

// Passo a passo para atualizar o repositório do Github pelo VScode: <br>
1. Use o comando 'git add + [nome do arquivo]' <br>
2. Use o comando 'git commit -m global' para permitir a atualização <br>
3. Use o comando 'git push' para executar a atualização <br>
